# nole-code

## Overview
AI coding assistant CLI — 31 tools, multi-provider, agentic tool loop, MCP server mode

## Tech Stack
TypeScript

## Commands
```bash
npm run dev    # bun run src/index.ts
npm run build  # bun build src/index.ts --outdir dist --t
npm test       # bun test
npm start      # node dist/index.js
```
